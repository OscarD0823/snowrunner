# Política de privacidad / Privacy policy

Última actualización: 1 de octubre de 2026.

## Español

Offroad XML Studio (también identificado fuera de Microsoft Store como SnowRunner Studio) funciona de forma local. No crea cuentas, no incluye publicidad, no usa analítica y no envía al desarrollador archivos del juego, mods, partidas ni datos personales.

La aplicación accede únicamente a las carpetas que el usuario selecciona para leer y modificar archivos XML compatibles. Las copias de seguridad, preferencias, imágenes extraídas y carátulas personalizadas se guardan en el equipo del usuario. Al desinstalar, Windows puede conservar copias de seguridad creadas junto a la instalación del juego para evitar pérdida accidental.

La edición distribuida fuera de Microsoft Store puede consultar GitHub para comprobar si existe una versión nueva. Esa consulta está sujeta a la política de privacidad de GitHub y transmite la información técnica normal de una conexión HTTPS, como la dirección IP. La edición de Microsoft Store usa únicamente el sistema de actualizaciones de la tienda.

SnowRunner y sus recursos pertenecen a sus respectivos titulares. La aplicación no incluye archivos ni carátulas del juego; solo procesa los que ya existen en la instalación legítima del usuario. Este proyecto no está afiliado, respaldado ni patrocinado por Saber Interactive o Focus Entertainment.

Consultas de privacidad: abre una incidencia en https://github.com/OscarD0823/snowrunner/issues

## English

Offroad XML Studio (also identified outside Microsoft Store as SnowRunner Studio) runs locally. It creates no accounts, contains no advertising, uses no analytics, and does not send game files, mods, save games, or personal data to the developer.

The app only accesses folders selected by the user to read and modify compatible XML files. Backups, preferences, extracted images, and custom covers stay on the user's device. Windows may leave backups created next to the game installation after uninstalling to prevent accidental data loss.

The edition distributed outside Microsoft Store may contact GitHub to check for updates. This request is governed by GitHub's privacy policy and transmits normal HTTPS connection data such as the IP address. The Microsoft Store edition only uses Store updates.

SnowRunner and its assets belong to their respective owners. The app does not include game files or game covers; it only processes files already present in the user's legitimate installation. This project is not affiliated with, endorsed by, or sponsored by Saber Interactive or Focus Entertainment.

Privacy questions: open an issue at https://github.com/OscarD0823/snowrunner/issues
