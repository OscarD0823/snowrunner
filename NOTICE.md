# Avisos de terceros

Este proyecto deriva de **SnowRunner XML Editor Desktop**, creado por VerZsuT:

https://github.com/VerZsuT/SnowRunner-XML-Editor-Desktop

El código original se distribuye bajo la licencia MIT incluida en `LICENSE`.
La edición en español, el rediseño de interfaz y las mejoras de usabilidad fueron realizados para SnowRunner Studio.

La lectura y escritura de contenedores ZIP usa `fflate` y `yauzl`. La
decodificación local de texturas BC1-BC7 usa `tex-decoder` y su dependencia
`bireader`. Estas dependencias se distribuyen bajo licencia MIT. La aplicación
no incorpora WinRAR, 7-Zip ni otro ejecutable de archivado externo.
